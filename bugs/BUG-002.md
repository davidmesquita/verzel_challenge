# BUG-002 — API aceita mais de cinco unidades por produto

## Resumo

A API aceita quantidade 6 para o mesmo produto, embora a regra oficial limite cada produto a cinco unidades tanto na interface quanto na API.

## Severidade

Alta

## Prioridade

Alta

## Ambiente

- URL: https://verzel-store.qa-test-verzel-store.workers.dev/
- Endpoints: `POST /api/carrinho/calcular` e `POST /api/pedidos`
- Navegador: Chromium integrado
- Data: 2026-10-06

## Pré-condições

- Requisição JSON válida com cliente válido para `/api/pedidos`.

## Passos para reproduzir

1. Enviar `POST /api/carrinho/calcular` com `itens: [{"produtoId":"P005","quantidade":6}]`.
2. Enviar `POST /api/pedidos` com o mesmo item e cliente válido.

## Resultado esperado

- Os dois endpoints rejeitam a requisição com HTTP `422` e código `QUANTIDADE_MAXIMA_EXCEDIDA`.

## Resultado atual

- `/api/carrinho/calcular` responde `200`, subtotal `600`, frete `0` e total `600`.
- `/api/pedidos` responde `201` e confirma pedido com quantidade `6`.
- A interface impede a sexta unidade; portanto, a regra não está consistente entre UI e API.

## Controle verificado

- Quantidade `5` em `/api/pedidos` é aceita com HTTP `201`.
- Quantidades `0`, `-1` e `1.5` são rejeitadas com HTTP `422` e código `QUANTIDADE_INVALIDA`.

## Impacto

Clientes podem contornar o limite por chamada direta à API, tanto no cálculo quanto na confirmação do pedido.

## Status

Reproduzido; aguardando correção
