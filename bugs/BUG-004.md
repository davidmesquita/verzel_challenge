# BUG-004 — API retorna códigos incorretos para item malformado

## Resumo

`POST /api/pedidos` não retorna o código `ITEM_INVALIDO` documentado quando um item não contém `produtoId` ou `quantidade`.

## Severidade

Baixa

## Prioridade

Média

## Ambiente

- URL: https://verzel-store.qa-test-verzel-store.workers.dev/
- Endpoint: `POST /api/pedidos`
- Navegador: Chromium / Playwright APIRequest
- Data: 2026-10-06

## Pré-condições

- Enviar uma requisição JSON com dados válidos de cliente.

## Passos para reproduzir

1. Enviar `itens: [{"quantidade":1}]`, sem `produtoId`.
2. Repetir com `itens: [{"produtoId":"P005"}]`, sem `quantidade`.

## Resultado esperado

- Ambas as requisições respondem HTTP `422` com código `ITEM_INVALIDO`, conforme a tabela de erros da documentação.

## Resultado atual

- Sem `produtoId`: HTTP `422`, código `PRODUTO_NAO_ENCONTRADO`.
- Sem `quantidade`: HTTP `422`, código `QUANTIDADE_INVALIDA`.

## Status

Reproduzido; aguardando correção.
