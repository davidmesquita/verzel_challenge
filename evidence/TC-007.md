# EV-007 — Dados inválidos no checkout

## O que foi testado
Validação do checkout com dados de cliente inválidos.

## Estado inicial
Carrinho pronto para finalizar a compra.

## Ação executada
Informou e-mail em formato inválido e tentou confirmar o pedido.

## Resultado observado
O sistema bloqueou a confirmação e manteve a validação documental consistente para cliente com dados incorretos.
